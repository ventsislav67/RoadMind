# RoadMind — Самооценка

## Описание

RoadMind реализира уеб платформа за подготовка за теоретичния шофьорски изпит категория B.

## Реализирани цели

- Работа с база данни
- Работа с въпроси и тестове
- Съхраняване на резултати
- Персонализирано обучение
- Интеграция с AI API
- Четлив и responsive интерфейс

## Бъдещо развитие

Като бъдещи подобрения могат да бъдат добавени допълнителни категории, разширена статистика и допълнителни AI функционалности.
