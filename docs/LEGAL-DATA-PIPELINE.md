# RoadMind - нормативен data pipeline

Пълният нормативен dataset не трябва да се пише ръчно. Pipeline-ът изтегля официалните PDF документи, извлича текст и създава article-level записи в seed/extracted.

## Команди

npm install
npm run laws:download
npm run laws:extract

## Източници

Основните източници са ЗДвП, ППЗДвП, Наредба 37, Наредба 38, пътни знаци, маркировка, светофари и първа помощ. Изпитните теми и официалният масив от изпитни въпроси се пазят като отделна изпитна рамка.

## Верификация

Всеки извлечен запис се маркира verified=false. Преди да стане RAG контекст за AI Tutor, трябва да се съпостави с действащия текст и измененията в Държавен вестник.

## Firestore

lawSources - описание на нормативните източници.
lawRules - конкретни разпоредби с sourceId и exactText.
topics - тематичен индекс.
categories - започваме с B.

AI Tutor използва само записи с country=BG и verified=true.
