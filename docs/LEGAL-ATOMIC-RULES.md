# RoadMind — атомарни нормативни правила

Този етап разделя вече извлечените членове на по-малки записи:

```text
член
  ↓
алинея
  ↓
точка
  ↓
буква
```

Парсерът е консервативен: когато структурата не може да бъде разпозната надеждно, записът не се представя като потвърден. Всеки запис остава с:

- `verified: false`
- `verificationStatus: needs_verification`
- `parentArticleId`
- `exactText`
- `sourceId`
- `article`
- `paragraph`
- `item`
- `letter`

## Стартиране

```bash
npm run laws:atomic
```

## Резултат

```text
seed/atomic/
├── lawRules.atomic.json
└── extraction-stats.json
```

## Важно

Този parser е технически инструмент за структуриране, а не правен валидатор. Преди production използване всяка релевантна норма трябва да бъде сверена с актуалния официален текст и измененията в Държавен вестник.

Следващият етап е тематично класифициране за категория B и правна верификация.
